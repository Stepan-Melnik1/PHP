## Цель работы

## Ход работы

### Часть 1. Условные конструкции

**Задача.** Используя функцию `date()`, построить таблицу с расписанием на основе текущего дня недели:

- John Styles работает в понедельник, среду и пятницу с 8:00 до 12:00;
- Jane Doe работает во вторник, четверг и субботу с 12:00 до 16:00;
- в остальные дни для каждого выводится «Нерабочий день».

**Решение.** Файл `index.php`:

```php
<?php
$day = date('N');

echo "Сегодняшний день недели по счёту: $day<br><br>";


if ($day == 1 || $day == 3 || $day == 5) {
    $johnSchedule = "8:00-12:00";
} else {
    $johnSchedule = "Нерабочий день";
}


if ($day == 2 || $day == 4 || $day == 6) {
    $janeSchedule = "12:00-16:00";
} else {
    $janeSchedule = "Нерабочий день";
}
?>

<table border="1">
    <tr>
        <th>№</th>
        <th>Фамилия Имя</th>
        <th>График работы</th>
    </tr>
    <tr>
        <td>1</td>
        <td>John Styles</td>
        <td><?php echo $johnSchedule; ?></td>
    </tr>
    <tr>
        <td>2</td>
        <td>Jane Doe</td>
        <td><?= $janeSchedule ?></td>
    </tr>
</table>
```

**Пояснение.**

- `date('N')` возвращает номер дня недели по стандарту ISO-8601: от 1 (понедельник) до 7 (воскресенье).
- Условие `$day == 1 || $day == 3 || $day == 5` истинно, если день равен одному из перечисленных значений (оператор `||` означает «или»).
- Результат условия сохраняется в переменную, а затем вставляется в ячейку таблицы через `<?php echo ... ?>` или короткую запись `<?= ... ?>`.

### Часть 2. Циклы

**Задача.** Дан цикл `for`, который на каждом шаге увеличивает `$a` на 10 и `$b` на 5. Нужно:

1. создать файл с этим кодом;
2. добавить вывод промежуточных значений `$a` и `$b` на каждом шаге;
3. переписать цикл с помощью `while` и `do-while`.

**Решение.** Файл `index1.php`:

```php
<?php
$a = 0;
$b = 0;

// цикл for
echo "===== Цикл for ===== <br>";
for ($i = 0; $i <= 5; $i++) {
    echo "Шаг $i) a = $a и b = $b <br>";
    $a += 10;
    $b += 5;
}

echo "End of the loop with for: a = $a, b = $b <br><br>";

// цикл while
echo "===== Цикл while ===== <br>";
$i = 0;
$a = 0;
$b = 0;

while ($i < 6) {
    echo "Шаг $i) a = $a и b = $b <br>";
    $a += 10;
    $b += 5;

    $i++;
}

echo "End of the loop with while: a = $a, b = $b <br><br>";

// цикл do-while
echo "===== Цикл do-while ===== <br>";
$i = 0;
$a = 0;
$b = 0;

do {
    echo "Шаг $i) a = $a и b = $b <br>";
    $a += 10;
    $b += 5;

    $i++;

} while ($i < 6);

echo "End of the loop with do-while: a = $a, b = $b <br><br>";
?>
```

**Пояснение.**

- Тело цикла выполняется 6 раз (`$i` принимает значения 0, 1, 2, 3, 4, 5), потому что условие `$i <= 5` нестрогое.
- В `for` инициализация, условие и шаг записаны в заголовке. В `while` и `do-while` инициализация пишется до цикла, а шаг `$i++` внутри тела.
- Перед каждым новым циклом переменные `$a`, `$b`, `$i` обнуляются, иначе они сохранили бы значения от предыдущего цикла.
- Промежуточный `echo` стоит до изменения `$a` и `$b`, поэтому на каждом шаге выводятся значения, которые были на входе в этот шаг.

**Результат.** Все три цикла дают одинаковый вывод:

```
Шаг 0) a = 0 и b = 0
Шаг 1) a = 10 и b = 5
Шаг 2) a = 20 и b = 10
Шаг 3) a = 30 и b = 15
Шаг 4) a = 40 и b = 20
Шаг 5) a = 50 и b = 25
End of the loop: a = 60, b = 30
```

## Контрольные вопросы

### 1. В чем разница между циклами `for`, `while` и `do-while`? В каких случаях лучше использовать каждый из них?

Все три цикла повторяют тело, пока условие истинно. Различаются они тем, где записаны инициализация и шаг и в какой момент проверяется условие.

- `for` собирает инициализацию, условие и шаг в одной строке заголовка: `for ($i = 0; $i <= 5; $i++)`. Условие проверяется до каждого прохода. Лучше всего подходит, когда число повторений известно заранее (перебор чисел от 0 до 5, обход массива по индексам).
- `while` содержит в заголовке только условие: `while ($i <= 5)`. Инициализация пишется до цикла, а шаг внутри тела. Условие проверяется до прохода, поэтому если оно изначально ложно, тело не выполнится ни разу. Подходит, когда число повторений заранее неизвестно и цикл идёт «пока не наступит событие» (читать данные, пока они есть; искать, пока элемент не найден).
- `do-while` проверяет условие после тела: `do { ... } while ($i <= 5);`. Тело выполняется минимум один раз, даже если условие сразу ложно. После `while (...)` обязательна точка с запятой. Подходит, когда действие нужно выполнить хотя бы раз, а потом решить, повторять ли его (например, запрашивать ввод, пока пользователь не введёт корректное значение).

### 2. Как работает тернарный оператор `? :` в PHP?

Тернарный оператор это краткая форма записи `if / else`, которая возвращает значение. Синтаксис:

```php
условие ? значение_если_истина : значение_если_ложь
```
Сначала вычисляется условие. Если оно истинно, результатом выражения становится значение между ? и :, если ложно, то значение после :. Результат можно сразу присвоить переменной. Пример из этой работы, где график John Styles задан одной строкой вместо блока if / else:

```php
$johnSchedule = ($day == 1 || $day == 3 || $day == 5) ? "8:00-12:00" : "Нерабочий день";
```
Эта запись равносильна обычному условию из части 1. Тернарный оператор удобен для простого выбора из двух значений. Для сложной логики читаемее обычный `if`. Вложенные тернарные операторы без скобок в PHP 8 запрещены.

### 3. Что произойдет, если в `do-while` поставить условие, которое изначально ложно?
Тело цикла всё равно выполнится один раз, потому что условие проверяется только после первого прохода.

Для проверки в `do-while` из `index1.php` начальное значение было изменено на `$i = 10`, так что условие `$i < 6` ложно с самого начала. Результат: выполнился один проход и вывелась строка `Шаг 10) a = 0 и b = 0`. После него `$a` стало 10, `$b` стало 5, `$i` стало 11, проверка `11 < 6` дала ложь, и цикл завершился. Итоговый вывод: `a = 10, b = 5`.

Цикл `while` с теми же начальными значениями не выполнил бы тело ни разу: условие проверилось бы до входа в цикл, `$a` и `$b` остались бы равными 0. В этом и состоит главное отличие `do-while`: он гарантирует хотя бы одно выполнение тела.
