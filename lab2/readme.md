## Шаг 1: Установка PHP на Arch Linux
В Windows в задании предлагают скачивать архив с сайта PHP. На Arch это делать необязательно: PHP устанавливается через пакетный менеджер `pacman`.

Открываем терминал (ctrl+alt+t) и выполняем:
`sudo pacman -S php`


**Что здесь происходит?**
- sudo — выполнить команду с правами администратора.
- pacman — пакетный менеджер Arch Linux.
- -S — установить пакет.
- php — название устанавливаемого пакета.

Если система спросит:

`:: Proceed with installation? [Y/n]`

вводим: `Y` и нажимаем `Enter`.

## Шаг 4. Работа с переменными и выводом
### Создаём две переменные 
```php
$days = 288;
$message = "Все возвращаются на работу!";
```

### Конкатенация
Вот это: `echo $days . " — " . $message;` использует оператор: `.`. В PHP точка означает конкатенацию, то есть объединение строк.  
Например:
```php
$name = "Artemii";

echo "Привет, " . $name;
```
Получим: `Привет, Artemii`  
В нашем случае: `$days . " — " . $message` объединяет: `288 — Все возвращаются на работу!`

### Двойные кавычки
Мы также можем написать: `echo "$days — $message<br />";`. PHP внутри двойных кавычек понимает переменные и подставляет их значения. 

То есть: `"$days — $message"` превратится в: `288 — Все возвращаются на работу!`

А вот с одинарными кавычками: `echo '$days — $message';` PHP не подставит значения переменных. 

Выведется буквально: `$days — $message`

`<br />` — HTML-тег переноса строки.

Например:
```php
echo $days . " — " . $message . "<br />";
echo "$days — $message<br />";
```

## Контрольные вопросы

### 1. Какие способы установки PHP существуют?

На Linux PHP можно установить через пакетный менеджер дистрибутива. Например, в Arch Linux используется pacman:

`sudo pacman -S php`

Также PHP можно установить вручную с официального сайта PHP или использовать готовые среды разработки, например XAMPP.

### 2. Как проверить, что PHP установлен и работает?

Для проверки версии PHP в терминале используется:

`php -v`

Для проверки работы PHP через веб-сервер можно запустить встроенный сервер:

`php -S localhost:8000`

После этого открыть в браузере:

`http://localhost:8000`
### 3. Чем отличается echo от print?

Оба оператора используются для вывода данных.
```php
echo "Hello";
print "Hello";
```
Основное практическое отличие состоит в том, что print возвращает значение 1, а echo не возвращает значения. echo также позволяет выводить несколько аргументов, тогда как print принимает только один аргумент. Для обычного вывода текста в PHP часто используется echo.
