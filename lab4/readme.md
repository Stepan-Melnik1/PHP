## Задание 1. Работа с массивами

В файле `index.php` включена строгая типизация (`declare(strict_types=1);`). Транзакции хранятся в массиве `$transactions`. Каждая транзакция это ассоциативный массив с полями:

| Поле          | Описание                                  |
|---------------|-------------------------------------------|
| `id`          | уникальный идентификатор                  |
| `date`        | дата в формате `YYYY-MM-DD`               |
| `amount`      | сумма транзакции                          |
| `description` | описание платежа                          |
| `merchant`    | организация, получившая платёж            |

### Вывод списка транзакций

Транзакции выводятся в HTML-таблицу с помощью `foreach`. Строковые значения экранируются через `htmlspecialchars()`, сумма форматируется через `number_format()`. В таблице есть столбец «Days ago» (сколько дней прошло с момента транзакции), а в конце таблицы выводится общая сумма.

### Реализованные функции

| Функция | Описание |
|---------|----------|
| `calculateTotalAmount(array $transactions): float` | Считает общую сумму всех транзакций (цикл `foreach`; в комментарии приведён второй вариант через `array_sum` и `array_column`). |
| `findTransactionByDescription(string $descriptionPart): array` | Ищет транзакции по части описания с помощью `array_filter` и `str_contains`. Возвращает массив найденных транзакций (пустой, если совпадений нет). |
| `findTransactionById(int $id): ?array` | Ищет транзакцию по `id` с помощью цикла `foreach`. Возвращает транзакцию или `null`. |
| `findTransactionByIdFilter(int $id): ?array` | То же, но через `array_filter` с анонимной функцией и `use`. |
| `findTransactionByMerchant(string $merchant): ?array` | Дополнительная функция: поиск по названию организации через `array_filter`. |
| `daysSinceTransaction(string $date): int` | Возвращает количество дней между датой транзакции и текущим днём (класс `DateTime`, метод `diff`). |
| `addTransaction(int $id, string $date, float $amount, string $description, string $merchant): void` | Добавляет новую транзакцию в глобальный массив `$transactions` (через `global`). |

Все функции задокументированы в стандарте PHPDoc.

### Сортировка

Сортировка выполняется функцией `usort()` с анонимной функцией-компаратором и оператором `<=>`. Сортируются копии массива, чтобы не менять исходный порядок:

- по дате (по возрастанию): `$a["date"] <=> $b["date"]`;
- по сумме (по убыванию): `$b["amount"] <=> $a["amount"]`.

## Задание 2. Работа с файловой системой

В папке `gallery/` находится страница с хедером, меню, контентом и футером. В папке `image/` лежат изображения `.jpg`.

Работа галереи:

1. `scandir("image/")` получает список имён файлов в папке.
2. Список обходится циклом `foreach`.
3. Для каждого файла проверяется расширение: `strtolower(pathinfo($file, PATHINFO_EXTENSION)) === "jpg"`. Служебные записи `.` и `..` расширения не имеют, поэтому отсеиваются этой же проверкой.
4. Для подходящих файлов выводится тег `<img>` с путём `image/<имя файла>`.
5. Изображения отображаются адаптивной сеткой (CSS Grid).

## Контрольные вопросы

**1. Что такое массивы в PHP?**
Массив это упорядоченный набор данных, в котором каждое значение хранится под своим ключом. Ключи бывают числовыми (индексные массивы) или строковыми (ассоциативные массивы). Значениями могут быть любые типы данных, в том числе другие массивы (многомерные массивы).

**2. Каким образом можно создать массив в PHP?**
С помощью квадратных скобок или конструкции `array()`:

```php
$numbers = [1, 2, 3];                       // индексный массив
$user = ["name" => "Anna", "age" => 20];    // ассоциативный массив
$empty = [];                                // пустой массив
```

Новые элементы добавляются в конец через `$numbers[] = 4;`.

**3. Для чего используется цикл foreach?**
Цикл `foreach` предназначен для перебора элементов массива. На каждой итерации текущий элемент попадает в переменную цикла, а при записи `foreach ($array as $key => $value)` доступен ещё и ключ. В работе он используется для вывода транзакций в таблицу и для перебора файлов в галерее.
